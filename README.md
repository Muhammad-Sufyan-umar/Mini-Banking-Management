# Bank Management System

A simple Bank Management System built in **Python using Object Oriented Programming(OOP).**

This project allows user to create accounts, check account details, deposit, withdraw, transfer, and delete accounts through a simple command-line menu.

## Features

* Create Bank Account
* Generate Account Number
* Check Account Details
* Deposit Money
* Withdraw Money
* Transfer Money
* Delete Account
* Check Insufficient Balance
* Exit Application

## Technologies Used

* Python 3
* Object Oriented Programming
* Classes & Objects
* Lists
* Functions
* Loops
* Conditional Statements
* User Input
* Random Module

## Classes Used

### Bank

Manages bank accounts and provides methods to:

* Create Account
* Check Account Details
* Deposit Money
* Withdraw Money
* Transfer Money
* Delete Account

### Account

Stores account information such as:

* Account Number
* Account Holder Name
* Phone Number
* Balance

# Purpose of Project

This project was created to practice **Python OOP concepts** and understand how classes, objects, lists, and methods can work together in a simple real-world application.

Relationship between:

```text
Bank
|-> Accounts
```

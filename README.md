# 🏦 Bank Management System

A simple **Bank Management System** built with Python using **Object-Oriented Programming (OOP)** concepts.

This project allows users to create bank accounts, check account details, deposit and withdraw money, and transfer money between accounts.

## 🚀 Features

* 🧑 Create a new bank account
* 🔢 Generate a unique account number
* 📋 Check account details
* 💰 Deposit money
* 💸 Withdraw money
* 🔄 Transfer money between accounts
* ⚠️ Check for insufficient balance
* ⛔ Delete Account 
* ❌ Handle invalid menu choices
* 🚪 Exit the banking system

## 🛠️ Technologies Used

* **Python**
* **OOP (Object-Oriented Programming)**
* `random` module

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python bank.py
```

## 📋 Menu

When the program starts, the following menu is displayed:

```text
1. Create account.
2. Check account details
3. Deposit Amount
4. Withdraw Amount
5. Transfer Amount
6. Delete account
&. Exit
```

## 💡 Example

A user can create an account:

```text
Enter name: Sufyan
Enter Phone number: 03001234567
```

The system automatically generates an account number and starts the balance from `0`.

Users can then deposit, withdraw, or transfer money using their account numbers.

## 🔄 Transfer System

The transfer feature requires:

1. Sender's account number
2. Receiver's account number
3. Transfer amount

The system checks whether the sender has enough balance before completing the transfer.

## ⚠️ Note

This is a **practice/educational project** and does not represent a real banking system.

It currently stores account information only while the program is running. Data will be lost when the program is closed.
